## Vehicle photography

Vehicle photographs in `public/vehicles` and `public/vehicles/gallery` are used for educational demonstration. Most were retrieved from Wikimedia Commons searches for the named vehicle models.

Wikimedia Commons files can use different licences and attribution requirements. Before using this project commercially:

1. Identify the original Commons file page for every retained photograph.
2. Record the creator, source URL and exact licence.
3. Add attribution where required.
4. Replace any image whose licence is unsuitable for the intended distribution.

Vehicle names and manufacturer marks belong to their respective owners. Their appearance does not imply endorsement of this project.
