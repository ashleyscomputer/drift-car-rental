# Code of conduct

## Our standard

Contributors should create a welcoming, respectful and constructive environment. Be considerate in technical discussion, accept feedback professionally and focus criticism on the work rather than the person.

Harassment, discrimination, threats, deliberate intimidation and the publication of another person's private information are not acceptable.

## Scope and enforcement

This standard applies in repository discussions, issues, pull requests and other project spaces. Report unacceptable behaviour privately to the repository owner through their GitHub profile. The owner may edit or remove contributions and temporarily or permanently restrict participation when necessary.
